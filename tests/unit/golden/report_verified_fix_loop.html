How to reproduce

Re-run every oracle offline on the bundle and compare the verdicts with the manifest:

assay replay <bundle>

The replay first checks the sha256 of every file against the manifest and runs nothing when one differs. It needs Docker and the runner image (make image). It prints REPLAY MATCH when the verdicts are equal.
